CleanCat 是一款 100% 本地处理的 iOS 相册整理助手。它帮助用户按年份扫描相册，找出重复照片、相似照片、视频重复、截图、录屏和需要人工检查的低质量照片/视频，再由用户自己确认要保留或删除的内容。

照片不会上传到服务器，扫描和判断都在设备本地完成。

首次使用可享受 **7 天全功能免费试用**，试用期间所有功能完全开放。试用结束后可选择订阅或永久买断。

## 产品故事

轻猫的灵感来自一只叫“涂涂”的虎斑美短。

相册里总会有很多舍不得删、又确实需要整理的照片：连拍、截图、聊天记录、表情包、网页截屏、模糊照片，还有为了拍好猫咪而留下的一整串相似照片。

轻猫想做的不是替用户决定，而是像一只聪明的电子猫一样，把需要注意的照片轻轻扒拉到面前：

- 哪些照片完全重复
- 哪些照片看起来很相似
- 哪些截图和录屏已经堆积太久
- 哪些照片可能模糊或曝光异常，需要人工检查
- 哪些照片可以先预览、再决定是否删除

整理相册不应该是一件沉重的家务活。它应该轻一点、慢一点、放心一点。

## 当前 MVP 能力

- 按年份扫描相册，避免一次性处理几万张照片
- 自动识别截图和录屏，并对截图做内容分类（敏感证件/验证码/聊天/票据等）
- 检测完全重复照片、重复视频、重复 Live Photo（三类资源 hash 空间隔离，不会混淆）
- 检测相似照片并分组展示，相似组按保守策略给出"建议保留"
- 标记明显模糊、曝光异常、分辨率过低的照片以及过短视频、口袋录像，放入"待检查"列表
- 展示小图列表，并支持全屏左右滑动连续预览
- 支持用户手动选择、取消选择；在预览页内可直接选择或取消选择
- 对推荐保留照片进行选择保护，降低误删风险
- 对 iCloud 照片在扫描阶段不自动下载，用户主动预览时按需下载并显示进度
- 调用系统删除确认页，删除用户确认的照片；删除后跨年份缓存结果同步更新
- 批量删除按 100 张分批；单张失败自动降级，不会整批中断
- 扫描过程支持取消；前后台切换不会丢失已完成结果
- 本地记录基础使用事件，便于后续调试和体验优化
- 内置轻猫 App 图标与品牌视觉资源

## 核心实现

| 能力 | 实现方式 | 说明 |
| --- | --- | --- |
| 年份扫描 | Photos fetch + 日期过滤 | 支持按年分桶处理，已扫描结果缓存保留 |
| 截图/录屏识别 | PHAsset 元数据 + Vision OCR | 系统 subtype 识别 + 截图内容分类（敏感证件/验证码/聊天/票据/网页/App UI） |
| 重复检测 | 文件大小/尺寸/媒体类型预筛 + MD5 + hash 前缀隔离 | 照片 `p:`、视频 `v:`、Live Photo `lp:` 三类 hash 空间隔离，避免封面与照片误匹配 |
| 相似检测 | pHash + 颜色签名 + 4x4 tile 颜色构图 + 宽高比 + 10 分钟时间窗 + 人脸/宠物主体门 | 多层防线，保守分组；主体精检 96 张预算内惰性提取 |
| 视频低质量 | 关键帧黑帧判定 + 时长/分辨率阈值 | 口袋录像/镜头盖、过短、低分辨率三路；默认深度相似关闭 |
| 低质量照片 | 清晰度/曝光/对比度评分 | 仅提示人工检查，不自动纳入可清理空间 |
| 照片/视频预览 | PHImageManager / AVAssetImageGenerator | 小图列表 + 全屏左右滑动连续预览；iCloud 主动预览时按需下载 |
| 删除照片 | PHPhotoLibrary.performChanges + 100 张分批 | 系统确认页；单张失败自动降级；删除后同步更新所有年份缓存 |
| 状态保护 | scanID + Task cancel + AppState 生命周期管理 | 避免取消后旧任务回写界面；前后台切换保留已完成结果 |
| 7 天试用与付费 | UserDefaults 持久化 + hasFullAccess 门控 | `trialStartDate` 跨启动持久；到期后删除/建议保留触发付费墙；月 ¥18 / 年 ¥88 / 买断 ¥98（限时） |
| 隐私埋点 | 本地 NDJSON 日志 + 匿名 anon_id | 不写 photo_id、localIdentifier 等可逆标识；用户可从设置页一键退出 |

## 项目结构

```text
CleanCat/
├── App/                          # 应用入口与全局状态
├── Core/
│   ├── Analytics/                # 本地事件记录

│   ├── Assets.xcassets/          # AppIcon 资源
│   ├── Info.plist                # 权限与启动配置
│   └── cleancat-app-icon.png     # README 图标预览
└── UI/
    ├── Components/               # 通用组件
    ├── Delete/                   # 删除确认
    ├── Onboarding/               # 权限引导
    ├── Paywall/                  # 付费入口占位
    ├── Results/                  # 扫描结果
    ├── Scan/                     # 扫描首页与进度页
    └── Settings/                 # 设置页
```

## 构建与运行

1. 用 Xcode 打开 `CleanCat.xcodeproj`
2. 选择 iPhone 模拟器或真机
3. 配置 Signing Team
4. 运行 `CleanCat` scheme

真机测试需要授权相册访问。模拟器测试前需要先向模拟器相册导入照片。
